The default theme (Blogs Helsinki 2026) is designed to be used with the block editor. Unlike the previous default theme (HelsinkiUni 2017), editing content in the new theme works differently because it uses a block‑based approach. This guide briefly explains what blocks are and how you can use them to build your site.
